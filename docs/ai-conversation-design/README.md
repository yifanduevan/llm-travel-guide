# AI Conversation Design – Travel Planner

This repository contains 30 designed conversations for an AI-based travel planning web application.

## Structure
- `/conversations`: Individual conversation designs in YAML-style format
- Each conversation includes:
  - Scenario
  - User Input
  - AI Output
  - Observation / Reflection

## Purpose
The goal of this project is to explore how different user inputs influence AI-generated travel itineraries, including edge cases, iterative interactions, and user edits.
